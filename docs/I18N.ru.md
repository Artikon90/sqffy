# Локализация (i18n)

[English](./I18N.md) · **Русский** · [中文](./I18N.zh.md)

Строки интерфейса SQffy проходят через `src/i18n.rs`. Не пишите пользовательский текст прямо в `app`, `picker`, `meta`, `render`, `provision` или `mcp`. Добавьте ключ в файлы локалей.

## Файлы

| Путь | Роль |
| --- | --- |
| `locales/en.toml` | Язык по умолчанию и запасной вариант, если ключа нет |
| `locales/ru.toml` | Русский |
| `locales/zh.toml` | Китайский (简体) |
| `src/i18n.rs` | Загрузчик, `t` / `tr`, определение языка |

Каталоги **вшиваются при компиляции** (`include_str!`). Правка toml подхватывается следующей сборкой, не на лету. Вложенные таблицы TOML сплющиваются в ключи через точку (`picker.title`, `meta.help`).

## API

```rust
i18n::init(cli.lang.as_deref()); // один раз при старте
i18n::t("picker.title");
i18n::tr("picker.connecting", &[("name", &name), ("driver", "sqlite")]);
```

Плейсхолдеры в строках локали пишутся как `{name}`. Если ключа нет, возвращается сам ключ: на экране будет `picker.title`, а не пустая строка.

## Выбор языка

Побеждает первое совпадение:

1. `--lang` (`en`, `ru`, `zh`)
2. `SQFFY_LANG`
3. `LC_ALL`, затем `LC_MESSAGES`, затем `LANG`
4. `en`

`C` и `POSIX` пропускаются. Неизвестное значение откатывается к английскому.

`normalize_lang` оставляет основной подтег. `ru-RU` и `ru_RU` — это `ru`. `zh`, `zh-CN`, `zh-TW`, `zhcn`, `zhtw` и `cn` — это `zh` (один каталог, `locales/zh.toml`).

## Новый язык

1. Скопируйте `locales/en.toml` в `locales/<code>.toml` и переведите. Набор ключей оставьте тем же.
2. Добавьте ветку в `i18n::load_embedded` и плечо `match` в `normalize_lang`.
3. Упомяните код в строке языков README (`--lang`) во всех трёх README.
4. `cargo test`. Ключи, которые зовёт код, должны разрешаться; английский каталог остаётся запасным.

## Новая строка

1. Добавьте ключ в `en.toml`, `ru.toml` и `zh.toml` в то же вложенное место.
2. Вызовите из кода `t("…")` или `tr("…", …)`.
3. Ключи короткие и устойчивые: `area.thing` (`picker.ask_name`).

Не оборачивайте уже переведённое предложение в `format!`. Плейсхолдер живёт в каталоге, чтобы порядок слов мог отличаться в каждом языке.
