# Localization (i18n)

**English** · [Русский](./I18N.ru.md) · [中文](./I18N.zh.md)

SQffy UI strings go through `src/i18n.rs`. Do not hardcode user-facing text in `app`, `picker`, `meta`, `render`, `provision`, or `mcp`. Add a key to the locale files instead.

## Files

| Path | Role |
| --- | --- |
| `locales/en.toml` | Default, and the fallback when a key is missing |
| `locales/ru.toml` | Russian |
| `locales/zh.toml` | Chinese (简体) |
| `src/i18n.rs` | Loader, `t` / `tr`, language detection |

Catalogs are **embedded at compile time** (`include_str!`). A change to a toml file is picked up on the next build, not at runtime. Nested TOML tables are flattened to dotted keys (`picker.title`, `meta.help`).

## API

```rust
i18n::init(cli.lang.as_deref()); // once at startup
i18n::t("picker.title");
i18n::tr("picker.connecting", &[("name", &name), ("driver", "sqlite")]);
```

Placeholders use `{name}` syntax inside locale strings. A missing key returns the key itself, so a gap shows up on screen as `picker.title` rather than an empty line.

## Language resolution

First match wins:

1. `--lang` (`en`, `ru`, `zh`)
2. `SQFFY_LANG`
3. `LC_ALL`, then `LC_MESSAGES`, then `LANG`
4. `en`

`C` and `POSIX` are skipped. Unknown values fall back to English.

`normalize_lang` keeps the primary subtag. `ru-RU` and `ru_RU` are `ru`. `zh`, `zh-CN`, `zh-TW`, `zhcn`, `zhtw`, and `cn` are `zh` (one catalog, `locales/zh.toml`).

## Adding a language

1. Copy `locales/en.toml` to `locales/<code>.toml` and translate. Keep the key set identical.
2. Add a branch in `i18n::load_embedded` and a match arm in `normalize_lang`.
3. Mention the code in the README language line (`--lang`) in all three READMEs.
4. `cargo test`. Keys used from code should resolve; the English catalog remains the fallback.

## Adding a string

1. Add the key to `en.toml`, `ru.toml`, and `zh.toml` in the same nested place.
2. Call `t("…")` or `tr("…", …)` from code.
3. Prefer short stable keys: `area.thing` (`picker.ask_name`).

Do not format with `format!` around an already-translated sentence. Put the placeholder in the catalog so word order can change per language.
